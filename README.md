## Reto

### Impulso del turismo para la conservación del entorno y el bienestar de las comunidades

## Nuestra solución

Lani es una aplicación móvil gamificada que redirecciona a los turistas
hacia destinos alternativos y negocios tradicionales mediante misiones.

El turista puede descubrir lugares menos concurridos, realizar actividades,
responder trivias e interactuar con negocios y comunidades locales.

Al completar misiones, el usuario obtiene puntos que pueden utilizarse para
desbloquear recompensas e insignias.

Además, Lani utiliza la ubicación del turista para recomendar destinos
cercanos y mostrar el nivel de saturación turística de diferentes lugares.

## Impacto

Lani busca contribuir a distribuir el flujo turístico hacia lugares menos
concurridos y generar oportunidades para comunidades y negocios locales.

La información recopilada por la plataforma también puede ser utilizada
para analizar la actividad turística y apoyar iniciativas relacionadas
con conservación y desarrollo local.
