>Descripción de la Idea: Lani<

Nombre del reto
Impulso del turismo para la conservacion del entorno y el bienestar de las comunidades


Nuestra Solución:
Lani es una aplicación móvil que redirecciona en tiempo real a los turistas hacia rutas alternativas 
y negocios tradicionales mediante misiones dinámicas. El viajero extranjero disfruta de una experiencia 
auténtica y llena de propósito, interactuando con la población, respondiendo trivias y comprando directamente 
a artesanos, comedores y guías locales.

El Impacto:
Las organizaciones de desarrollo y conservación obtienen datos en tiempo real para proteger el ecosistema, 
mientras se mide de forma transparente el crecimiento económico y directo de las comunidades locales.
